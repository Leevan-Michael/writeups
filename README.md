# Cybersecurity Learning Journey

Welcome to my cybersecurity learning repository.

This repository is a collection of the hands-on work, labs, challenges, and security write-ups I have documented throughout my cybersecurity learning journey.

I explore different areas of cybersecurity through practical labs and continuous self-learning, with a primary focus on:

- Vulnerability Assessment & Penetration Testing (VAPT)
- Web & API Security
- Network Security
- Linux & Windows Security
- Privilege Escalation
- Active Directory & LDAP
- Security Tools and Methodologies
- CTFs and Cybersecurity Labs

I don't document every lab, challenge, or topic I work on as a complete write-up. Due to time and the amount of practical work involved, I document and publish the write-ups that I am able to complete and feel are useful to preserve for future reference.

The purpose of this repository is to:

- Document my practical cybersecurity experience and learning.
- Keep track of interesting attack paths, techniques, and methodologies.
- Create a personal reference for concepts and tools I have explored.
- Share selected write-ups that may be useful to others learning cybersecurity.

Most of the work documented here comes from authorized platforms and environments such as Hack The Box, TryHackMe, CTFs, and other security labs.

This repository represents an ongoing learning process rather than a complete record of everything I have studied or practiced. I continue to learn, experiment, and improve my skills through hands-on security research and labs.
